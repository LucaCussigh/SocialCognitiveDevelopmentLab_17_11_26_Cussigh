# How Children See Social Groups in Faces

**Outgroup or Outgroups? Mapping spontaneous face perception of social groups**

Presentation by Luca Cussigh.

View the slides on [GitHub Pages](https://lucacussigh.github.io/SocialCognitiveDevelopmentLab_17_11_26_Cussigh/).

## Deployment

The static Marp export and its image assets are in `site/`. GitHub Actions deploys that directory to GitHub Pages when changes are pushed to `main` or `master`.

To update the published slides, replace the export in `site/index.html` and update any required assets in `site/Images/`, then commit and push the changes. The original Markdown source and PDF are not included in this repository.
